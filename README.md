# One Piece PSA Card Store — Jastip Japan

A static storefront that auto-scrapes PSA-graded One Piece card listings from [Card Rush](https://www.cardrush-op.jp/product-group/37/) daily via GitHub Actions, converts prices to IDR with 30% markup, and lets customers order directly via WhatsApp.

---

## How it works

```
Card Rush PSA page (cardrush-op.jp)
        ↓ (GitHub Actions, daily 08:00 WIB)
scraper/scrape.py
        ↓
public/cards.json
        ↓
public/index.html  ←  customers browse here (GitHub Pages)
        ↓
WhatsApp DM → +6281281078994
```

---

## Setup (one-time, ~10 minutes)

### 1. Fork / create this repo on GitHub

Push all files as-is. Make sure the structure looks like:
```
.github/workflows/scrape.yml
scraper/scrape.py
public/index.html
public/cards.json        ← will be created by first scrape run
README.md
```

### 2. Enable GitHub Pages

1. Go to your repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/public`
4. Save → your store will be live at `https://<your-username>.github.io/<repo-name>/`

### 3. Enable GitHub Actions write permissions

The scraper needs to commit `cards.json` back to the repo:

1. Go to **Settings** → **Actions** → **General**
2. Scroll to **Workflow permissions**
3. Select **Read and write permissions**
4. Save

### 4. Run the scraper for the first time

1. Go to **Actions** tab in your repo
2. Click **Scrape Card Rush PSA Listings**
3. Click **Run workflow** → **Run workflow**
4. Wait ~3–5 minutes for it to finish
5. Check that `public/cards.json` was committed

After this, it runs automatically every day at 08:00 WIB.

## File structure

| File | Purpose |
|------|---------|
| `public/index.html` | The storefront customers visit |
| `public/cards.json` | Auto-generated by scraper; read by the HTML |
| `scraper/scrape.py` | Python scraper — runs in GitHub Actions |
| `.github/workflows/scrape.yml` | Daily schedule + manual trigger |

---

## Customization

| What | Where |
|------|-------|
| Markup % | `public/index.html` line: `const MARKUP = 1.30` |
| WhatsApp number | `public/index.html` line: `const WA_NUMBER = "628..."` |
| Scrape delay (be polite) | `scraper/scrape.py` line: `DELAY = 1.5` |
| Cron schedule | `.github/workflows/scrape.yml` — cron expression |

## Notes

- **Exchange rate** is fetched live from exchangerate-api.com each time a customer opens the page.
- **Prices are rounded up** to the nearest Rp 1,000.
- Cards marked `状態難` (poor condition) show a yellow "状態難" badge.
- Stock count comes directly from Card Rush; sold-out items won't appear after next scrape.
- GitHub Pages is free for public repos. For a custom domain, add a `CNAME` file to `/public`.
